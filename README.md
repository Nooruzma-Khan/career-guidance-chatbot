# 🤖 Career Guidance Chatbot

An AI-powered career guidance assistant built as a portfolio web app. Users can ask career-related questions and get intelligent responses to help navigate their professional journey.

🔗 **Live Demo:** [nooruzmakhan.vercel.app](https://nooruzmakhan.vercel.app)

---

## ✨ Features

- 💬 AI-powered chatbot for career guidance
- 🎨 Clean, responsive UI built with React and Tailwind CSS
- ⚡ Fast performance with Vite
- 📱 Mobile-friendly design
- 🚀 Deployed live on Vercel

## 🚀 Getting Started

```bash
git clone https://github.com/Nooruzma-Khan/career-guidance-chatbot.git
cd cyber-ai-codebase
npm install
npm run dev
```

Open [http://localhost:8080](http://localhost:8080) in your browser.
